# Leettest  

Leettest is a browser extension designed to enhance your LeetCode experience. Whether you're grinding for interviews or improving your problem-solving skills, Leettest provides extra QOL to make the process smoother and more effective.  

## Features  
- **Random Test Case Generator**  
  Automatically generate random test cases for problems, helping you test your solutions thoroughly without the hassle of creating them manually.  

- **Numeric Difficulty Ratings**  
  Go beyond the "Easy," "Medium," and "Hard" labels with precise numeric ratings that give you a better idea of each problem's difficulty.  

- **Live Company Tags**  
  Stay up to date with trending problems for specific companies. Leettest dynamically inserts company tags into questions based on previous data.  

## Installation  
1. Download the extension from [(https://chromewebstore.google.com/detail/leettest/diinamlcdbbpfebknmhajjaijpflnaoe?authuser=0&hl=en)].  
2. Follow the instructions to add it to your browser.  
3. Start practicing with LeetCode, now supercharged with Leettest!
